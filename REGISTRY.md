# Registry of content repos

Content repos known to use publication-md. The source of truth is [`registry.yaml`](registry.yaml);
add your repo there with a pull request (public or private — say how access is obtained).

| Name | Title | Owner / copyright | Access | Language |
|---|---|---|---|---|
| [grottan](https://github.com/speleo-se/grottan-markdown-content) | Grottan — Sveriges Speleologförbunds medlemstidning (1966–) | Sveriges Speleologförbund (SSF) — © SSF | private — on request to SSF | sv |

To work on one: `npm run content -- add <repo url>` (see README).
